## `voxel/` —— 体素光追（2026-10，最终放弃）

**目标**：为了拿到**分图层的光线遮挡**——上层画的东西能给下层投影，
层与层之间的光能互相照亮。2D 光追做不到这件事，因为无限薄的层挡不住平面内的光。

**做了什么**：把画布当成 `X×Y×Z` 的体素空间（`voxel_volume.h` 定义数据契约），
只渲染每列柱顶曲面的上半球辐照度，光在真正的 3D 里传播，于是标准 3D 光追的
优化全都能用。

| 文件 | 是什么 |
|---|---|
| `voxel_volume.h` | 数据契约：`VoxelVolume { X,Y,Z; color[]; emission[] }`，索引 `idx=(z*Y+y)*X+x` |
| `voxel_renderer.{h,cpp}` | CPU 实现。三种 GI：光源采样 / 体素锥追踪 VCT / Radiance Cascades |
| `voxel_gpu.cpp` | Radiance Cascades 的 OpenGL 4.3 compute 版 |
| `vox_test.cpp` | headless 测试：环对称性、遮挡判定、与反向光追的数值对照 |

### 实测数字（都在这份记录里留档）

```
vox_test 160x96x16，GI 关闭        ≈ 1.19 ms
Radiance Cascades CPU（K0=32）     ≈ 94 ms/帧
Radiance Cascades GPU              ≈ 4.5 ms/帧   （20 倍）
VCT 单帧                           与 RC 同量级
```

与**反向光追（光源采样）**参照物的平均差（相对 255）：

```
RC  (K0=32, L0=2, 7 层)   1.49     最大差 71
VCT (64 锥)               0.71     最大差 50
```

### 为什么放弃

**整体光效不如 2D 光追，而换来的只是局部的一处遮挡关系。**

* **VCT**：角度分辨率固定 -> 远处锥的足迹覆盖不匀 -> **光斑**。
  实测等距圆环的不匀度：9 锥 621、32 锥 215、**64 锥才 54**（千分比）。
  也就是要靠堆锥才能压下去，代价是速度。
* **RC**：角度分辨率随距离翻倍，理论上更优，实测也确实无噪声；
  但 CPU 要 94 ms，GPU 版才有 4.5 ms，而 2D 光追是 **728 方向 182 fps**。

结论：**为一处局部的遮挡关系牺牲整体光效，不划算。**

### 这一段里踩过的坑（同类问题别再犯）

1. **同名遮蔽**：局部 `vec3 acc` 把 SSBO 数组 `acc` 遮住，
   `acc[bi]` 变成给 vec3 下标 -> 编译报 `atomicAdd(float,uint)` 找不到重载。
   （同一类错误在 `voxel_gpu.cpp` 里又犯过一次，所以那条 SSBO 现在叫 `accbuf`。）
2. **粗细层的平均会稀释不透明度**：mip 层 L 的一个 texel 是 `2^L³` 个体素的平均，
   一层不透明板只占块里很小一部分 -> 平均后 a 很小 -> `T*=(1-a)` 几乎不掉 ->
   **光从板子里漏过去**。修法：`a' = 1-(1-a)^(2^L)`，并且**要限制最大 mip 层级**
   （太粗的块会把遮挡物和它上方的光源装进同一块，补偿只是近似）。
3. **俯视下，正上方的遮挡物自己就是柱顶**。
   所以"被遮挡的表面"和"遮挡物"**必须不在同一列**才测得出来——
   我一开始就是拿同一列去量，量到的"漏光"其实是板子顶面被正常照亮，白查了一轮。
4. **定点原子累加的精度**：大 cascade 每条射线的贡献只有 `~1e-6`，
   直接 `×65535` 取整会变成 **0**，整个远场消失。
   修法：把常数挪到后处理再乘，只存 cos 加权的辐射。
5. **纹理单元撞车**：光场绑到 unit 1/2，而 unit 1 上已经绑着不透明度数组，
   覆盖之后光场整个消失。改用 3/4。
